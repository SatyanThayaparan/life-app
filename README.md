# ✳ LifeWrapped

**Spotify Wrapped for your life.** A mobile-first personal activity tracker that turns everyday moments into shareable monthly and yearly recaps.

## Features
- Log activities with category, date, duration and optional notes.
- View monthly or yearly activity counts, total hours, active days, category breakdown and recent moments.
- Generate and download a 900 × 1200 PNG recap card.
- Works on phones and desktops. Data is stored locally in your browser using localStorage.

## Run
No installation required. Open `index.html` in a browser, or serve this folder with a static server (for example `python3 -m http.server 8000`).

## Deploy
Deploy as a static site with GitHub Pages, Netlify or Vercel. Merge this PR to main before deploying from main.

## Privacy and limitations
Entries stay in the current browser/profile; there is no account, cloud sync, backup, or cross-device access yet. Clearing browser data can erase entries. Google Fonts require internet; system fonts are used as fallback. Recap cards are generated locally.
